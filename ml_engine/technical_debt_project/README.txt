TECHNICAL DEBT PREDICTION PROJECT
=================================

Project: Predictive Engineering Intelligence Platform for Technical Debt Prioritization

Files:
- technical_debt_prediction.py : corrected end-to-end project code
- technical_debt_ml_dataset.csv : supplied dataset
- original_pasted_code.py : earlier pasted code retained for reference

Workflow:
Feature Dataset -> Preprocessing -> Feature Selection -> Technical Risk Calculation
-> Historical Analysis -> ML Model -> Hotspot Prediction -> Model Evaluation
-> Explainability -> Structured Prediction Output

Run on Mac:
python3 technical_debt_prediction.py

When asked for the CSV filename, enter:
technical_debt_ml_dataset.csv

The program also accepts new component feature values from the user after training.
